# 6. Requisitos Futuros

Funcionalidades de longo prazo, para depois do MVP e da versão 2.

| ID | Requisito futuro | Motivo do adiamento |
|----|------------------|---------------------|
| RFut01 | Videochamadas entre candidatos e mentores/bolseiros, com agendamento. | Maior complexidade técnica e maior consumo de dados. |
| RFut02 | Chat em tempo real entre candidatos e mentores/bolseiros. | Exige infraestrutura de comunicação em tempo real e moderação reforçada. |
| RFut03 | Pagamento real das mentorias (integração com um meio de pagamento). | No MVP o pagamento é simulado; o pagamento real exige integração e análise das regras legais e financeiras. |
| RFut04 | Aplicação móvel (Android e iOS). | Esforço de desenvolvimento adicional; o site responsivo cobre o essencial. |
| RFut05 | Alertas por WhatsApp ou SMS. | Depende de serviços externos e custos de envio. |
| RFut06 | Versão do site noutras línguas (ex.: inglês). | Prioridade menor para o público inicial. |
| RFut07 | Recomendação personalizada de bolsas com base no perfil do candidato. | Requer dados suficientes e lógica de correspondência. |
| RFut08 | Importação semiautomática de bolsas a partir de fontes oficiais, sempre com revisão manual antes de publicar. | Exige análise dos termos de utilização das fontes e manutenção técnica; ver `07-metodo-recolha-bolsas.md`. |
